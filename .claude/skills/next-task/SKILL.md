## next-task

次に着手すべきタスクを機械的に判定する。

### 優先順位

1. 着手可能なタスクのうち、他の作業をブロックしているもの（`--dep` の依存先になっているもの）
2. 着手可能なタスクのうち、登録順（タスク ID）が早いもの

この基準で決められない場合のみユーザーに確認する。

### Steps

1. `backlog task list --plain` で着手可能なタスク一覧を確認する（priority の降順で並ぶ。`backlog board` の並びは順序の根拠にしない）
   - 「着手不可」（レビュー待ち・他タスク完了待ち・仕様未確定などが notes に記載されている）タスクは、その理由が解消しているか確認した上で対象外とする
   - 他タスクの依存先になっているものを優先する
2. 決まらない場合は、タスク ID が小さいものを選ぶ。ordinal は順序の根拠にしない
3. 候補タスクと選定理由（どの優先順位ルールに合致したか）を提示し、着手してよいかユーザーに確認する
4. 同率の候補が複数残る場合は、判定を打ち切りユーザーに選択を委ねる
