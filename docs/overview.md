# 機能の概要

配信元サイトではなく **内容** を軸にした、AI 活用型の RSS ツール。

## 機能

| 機能 | 概要 | 状態 |
| --- | --- | --- |
| フィード登録 | RSS/Atom の URL を登録する | 未着手 |
| 定期クロール | 約 1 時間ごとに登録フィードを取得する | 未着手 |
| 重複排除 | 複数フィードに載る同じ記事を、正規化 URL（permalink）の一致で 1 件にまとめる | 未着手 |
| ジャンルによる選別 | フィード（サイト）にジャンルを付け、「技術は読む／占いは読まない」のようにジャンル単位で include/exclude する。複合的なサイトや個別の記事だけ Jev で判定する（[ADR-0011](adr/0011-ai-scope.md)） | 未着手 |
| 後で読む | 気になる記事を保存し、後から読める形で残す | 未着手 |

## 後で読む: 保存形式の候補

軽さを重視。決定は ADR で行う（未決）。

| 形式 | 長所 | 短所 |
| --- | --- | --- |
| Markdown | 最軽量。検索・AI 処理と相性が良い | レイアウトや画像が落ちる |
| .webarchive | 見た目をそのまま保存 | Apple 固有で重く、Web 上で扱いにくい |
| PDF | どこでも開ける | 重く、テキスト抽出が必要 |

## 非目標

- ソーシャル機能、共有
- 配信元サイトの購読管理を閲覧の軸にすること（閲覧の軸はジャンル。サイトはジャンルを付ける単位として扱う）
