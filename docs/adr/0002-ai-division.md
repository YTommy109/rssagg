# ADR-0002: AI の分担は Jev（判断）と Workers AI（埋め込み）

- 状態: 置換（[ADR-0011](0011-ai-scope.md)）
- 日付: 2026-10-13

## 背景

記事の重複排除とカテゴライズに AI を使う。候補は Jev（TypeSafe の判断系モデル）、OpenAI、Gemini。想定規模は 200 サイト、1 日 1,000 記事。

## 決定

- 重複排除は段階式にする。URL 正規化 → 本文ハッシュ → 埋め込み類似度 → 微妙な組だけ Jev で「同じ話題か」を判断。
- カテゴライズと除外条件の判定は Jev（Noul/Choice/Score）で行い、確率のしきい値で選別する。同一記事への質問は 1 リクエストにまとめる。
- 埋め込みは Workers AI（多言語モデル）、保存は Vectorize。
- OpenAI と Gemini は当面使わない。プロバイダ切替の抽象化層も作らない。

## 理由・検討した代替案

- Jev の料金は入力 $0.042 / 100 万トークン、出力無料（docs.typesafe.ai/models、2026-10-13 確認）。1 日 1,000 件、1 件約 1,000 トークンで月約 $1.3、本文全文でも約 $6.3。
- 埋め込みを Workers AI にすると Cloudflare 内で完結し、外部キーが要らない。
- OpenAI / Gemini は用途が見当たらない。要約や判断の再確認が必要になった時点で追加する。

## 影響

- 日本語記事での Jev の判定精度と実トークン数は、実データで検証する。精度が足りなければ埋め込みを OpenAI に替える、または LLM による再判定を足す。
- プラン体系・無料枠は docs に記載がなく、契約面は別途確認する。
