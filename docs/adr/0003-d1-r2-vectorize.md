# ADR-0003: 保存先は D1 / R2 / Vectorize

- 状態: 採用
- 日付: 2026-10-13

## 背景

200 サイト、1 日約 1,000 記事（年約 36 万件）を保存し、重複判定と選別を行う。

## 決定

- D1: フィード、記事のメタデータ・要約・抜粋、判定結果、既読・保存状態。
- R2: 「後で読む」で保存した記事の全文アーカイブのみ。
- Vectorize: 重複判定用の埋め込み。

## 理由・検討した代替案

- 年約 2GB 程度に収まる見込みで、リレーショナルな管理には SQLite 系の D1 が自然。
- 全文を D1 に入れると肥大するため、保存した記事だけ R2 に置く。
- Postgres + Hyperdrive など外部 DB は、今の規模では取る理由がない。

## 影響

- アーカイブ形式（Markdown / .webarchive / PDF）は別 ADR で決める。
- 規模が 10 倍を超えるか、D1 の制約に当たった時点で見直す。
