# ADR-0010: htmx は CDN から、バージョンを固定して SRI つきで読み込む

- 状態: 採用
- 日付: 2026-10-18

<!-- constrained-by ./0006-htmx-hyperscript-sse.md -->

## 背景

画面は htmx で部分更新する（[ADR-0006](0006-htmx-hyperscript-sse.md)）。htmx 本体をブラウザへ届ける方法として、CDN から読み込む案と、Worker の静的アセットとして自前で配信する案がある。

## 決定

- htmx は jsDelivr（`cdn.jsdelivr.net/npm/htmx.org@<版>/dist/htmx.min.js`）から読み込む。
- 版は完全に固定し（`@2.0.11`）、`integrity`（SRI）と `crossorigin="anonymous"` を付ける。
- URL と SRI は `src/views/layout.tsx` の 1 か所で持つ。
- SRI は、CDN から取ったファイルと npm の tarball（レジストリの整合性ハッシュで検証したもの）が同一であることを確かめた上で計算する。更新時も同じ手順を踏む。
- hyperscript は、画面内の振る舞いが必要になるまで読み込まない。

## 理由・検討した代替案

- 利用者は 1 人で、常にネットワークにつながっている前提で使う。CDN に載せるだけで足りる。
- 版を固定して SRI を付ければ、CDN 側でファイルが書き換えられても、ブラウザが読み込まない。
- **静的アセットとして自前配信する案**: 採らない。`assets` バインディングを足し、Access の検証を静的ファイルにも効かせるために `run_worker_first` を設定する必要がある。vitest 側の設定も増える。得られるのはオフラインでの動作だけで、今は要らない。
- **npm の依存にしてビルドで取り込む案**: 採らない。フロント専用のビルド工程を持たないのが ADR-0006 の前提。

## 影響

- ネットワークにつながっていないと、画面は表示できるが htmx による部分更新が動かない。
- htmx の版を上げるときは、`layout.tsx` の URL と SRI を同時に更新する。
- 自前配信へ切り替える必要が出たら（オフラインで使う、CDN を許可しないなど）、この ADR を置き換える。
